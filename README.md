# ULX3S-playground
Playing around witht the ULX3S FPGA platform

## Tooling

It is expected that you have a release of the Yosys [oss-cad-suite](https://github.com/YosysHQ/oss-cad-suite-build) under a directory of the same name in this repo.
You can either download a release and extract it here, or extract it somewhere else and symlink it to this directory, both work.
